# نادي عائلة ناصر

موقع لمباريات العيلة: الإدارة بتنشر مباراة وبتبعتها لغروب العيلة على الواتساب بضغطة زر، واللاعبين بصوّتوا "سأحضر" أو "معتذر". الإدارة كمان بتتابع الاشتراك الشهري.

Spring Boot 4 + PostgreSQL، والواجهة HTML و JavaScript عادي بدون frameworks.

## الواتساب

ما في أي ربط مع API ولا تسجيل. أزرار لوحة الإدارة بتفتح الواتساب والرسالة جاهزة، والأدمن بيختار الغروب وبيبعث:
- **شارك المباراة**: اليوم والساعة والمكان والملاحظة ورابط التصويت.
- **ذكّر اللي ما صوّتوا**: أسماءهم ورابط التصويت.
- **شارك قائمة الجايين**: قائمة مرقّمة.

## متغيرات البيئة (Environment variables)

| المتغير                                                     | ضروري؟      | شو هو                                                                   |
|-------------------------------------------------------------|-------------|-------------------------------------------------------------------------|
| `SPRING_DATASOURCE_URL`                                     | نعم         | رابط قاعدة البيانات، مثل `jdbc:postgresql://host:5432/db`               |
| `SPRING_DATASOURCE_USERNAME` / `SPRING_DATASOURCE_PASSWORD` | حسب القاعدة |                                                                         |
| `ADMIN_PASSWORD`                                            | أول مرة بس  | إذا ما في حساب إدارة، بينعمل حساب باسم `ADMIN_NAME` (الافتراضي `Admin`) |

## تسجيل الدخول

لما حدا يسجّل دخول، السيرفر بيعطي المتصفح مفتاح، والصفحة بتحفظه وبتبعته مع كل طلب بـ header اسمه `X-Auth-Token`. ما في cookies، لأنه سفاري على الآيفون ما كان يحتفظ فيها. المفاتيح محفوظة بجدول `auth_tokens`، فالناس بتضل مسجّلة بعد كل تحديث للموقع، والمفتاح بيخلص بعد 90 يوم.

## تعديل ملفات الـ CSS والـ JavaScript

الصفحات بتحمّل `js/app.js?v=2` و `css/app.css?v=2`. إذا عدّلت أي واحد منهم، زيد الرقم (`v=3`…) بالصفحات الثلاث (`login.html` و `player.html` و `admin.html`)، وإلا سفاري على الآيفون ممكن يضل يستخدم النسخة القديمة.

## التشغيل محلياً

```bash
export SPRING_DATASOURCE_URL=jdbc:postgresql://localhost:5432/nasser
export SPRING_DATASOURCE_USERNAME=postgres SPRING_DATASOURCE_PASSWORD=postgres
export ADMIN_PASSWORD=change-me
mvn spring-boot:run
```

بعدها افتح http://localhost:8080

## الترقية من النسخة القديمة

ما في داعي تعمل إشي يدوي. عند أول تشغيل، `StartupTasks` بترتّب قاعدة البيانات الموجودة:
- كلمة سر الإدارة القديمة بتضل شغالة، وأول ما تدخل فيها بتتخزّن مشفّرة (BCrypt).
- علامات "دافع" القديمة بتنتقل لجدول `payments` للشهر الحالي.
- التصويتات الفاضية والمكررة بتنمسح.
